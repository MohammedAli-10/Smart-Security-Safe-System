# Smart-Security-Safe-System
Embedded smart safe system with keypad, sensors, LCD and alarm

---

## Project Overview
A smart electronic safe system designed to provide multi-layer security using password and physical key authentication with a user-friendly LCD interface.

---

## Main Features
- Password and key-based access control
- EEPROM password storage
- Anti-theft and transportation protection mode
- LCD menu-based interface
- Real-time alarm system with multiple sensors

---

## Security System
- 4 SW-520D vibration sensors for full coverage detection
- Magnetic door switch for unauthorized opening detection
- Alarm triggers on:
  - Wrong password attempts (3 times)
  - Vibration detection in protection mode
  - Unauthorized door opening
- Alarm can only be disabled using the physical key

---

## LCD & User Interface
- Auto backlight OFF after inactivity
- Auto return to menu after 20 seconds idle
- Password hidden as *
- `*` toggles visibility
- `#` deletes last digit
- `B` returns to main menu
- Sound feedback for actions and errors
